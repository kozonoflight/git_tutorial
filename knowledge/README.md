# 企業分析ナレッジベース

引き合い企業のビジネスモデル構造化・EC/受発注要件整理のための知見蓄積用リポジトリ。

## フォルダ構成

```
knowledge/
├── README.md                 # このファイル（運用ルール）
├── _template.md              # 分析ドキュメントのテンプレート
└── {業界名}/
    └── {会社名}.md           # 企業ごとの分析
```

- **業界フォルダ**: 同業他社が増えると、商習慣・システム傾向・要件パターンが横断でたまる
- **会社ファイル**: 1社1ファイル。ファイル名は正式社名

## 分析の進め方

1. **引き合い時点** — 公開情報（公式HP等）＋仮説で初稿を作成
2. **壁打ち** — 事実／推測／要確認を整理しながら更新
3. **ヒアリング後** — Pain・予算・現場の声を追記し、推測を事実に差し替え

## 情報の扱い

| 種別 | 扱い |
|------|------|
| HP等で確認できる事実 | そのまま記載（出典URLを添える） |
| 引き合い前に不明な項目 | **推測**と明記、または空欄 |
| 予算 | 分からなければ空欄でよい |
| 現場の困りごと | 初期は推測＋要確認リスト |

## 調査タスク（エージェント）

新規企業の依頼時、エージェントは以下を実施する：

- 公式サイト・会社概要・沿革の調査
- 事業内容・店舗・既存EC/通販の有無
- 業界・商習慣の文脈での仮説整理
- テンプレートに沿った初稿の提示
