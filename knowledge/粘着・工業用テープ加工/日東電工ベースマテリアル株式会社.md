## 2. BtoB EC：テープおまかせナビ

| 項目 | 内容 |
|------|------|
| サイト名 | テープおまかせナビ |
| URL | https://tape-omakase-navi.com/ |
| 対象 | 日本国内法人 |
| 基盤 | **EC-Rider B2B**（旧CSシステム時代のハルイチ／ハル工房事例として公開） |
| 取扱規模感 | 約3,800品種のうち、サイト掲載は約600商品・8万アイテム級 |
| CS規模感 | 年間約60万件のお問い合わせ実績（公式訴求） |

### 主な機能・導線（公開から読み取れるもの）

1. **カタログ購入** — 機能・用途・お悩みから探して注文  
2. **相談・サンプル** — プロへの相談、サンプル／資料請求  
3. **見積** — ロット等に応じた見積依頼  
4. **お客様専用ボックス** — 会員向けに提案商品・見積を投稿し、そこから購入  
5. **定型カスタム** — mm単位の幅指定、1巻から購入、工場直送の短納期訴求  
6. **法人会員** — 登録後に専用機能・提案が使える

### 公開されている顧客利用パターン（事例ページ）

- 廃番・代替品の相談 → 専用ボックスで見積 → 購入  
- サンプル評価 → 専用ボックス見積 → 購入  
- 価格相談 → 専用ボックス → 継続購入（ネット注文で時間短縮）

## 3. EC-Rider公開事例との関係

- EC-Rider公式事例「日東電工CSシステム」＝**同一法人の旧称時代**  
- 当時のサービス名としてハルイチ／ハル工房／ハルメイド（オーダーメイド印刷テープ＋デザインツール連携）が紹介されている  
- 現在の主力法人向け相談・購入サイトは**テープおまかせナビ**として展開

→ 「テープ業界でEC-Riderが、カタログ＋カスタム＋見積〜注文を載せてきた実績」として大協提案に使える。

## 4. 大協技研への流用メモ（要約）

詳細は大協ファイル §2.5。ここでは結論のみ。

| 流用する | そのままコピーしない |
|----------|----------------------|
