## 2. 図2：仕入・入荷・在庫フロー

`yh_asis_fig2_inventory.png`

### 論点：在庫はどちら起点か（ユーザーの疑問への回答）

> 「在庫の入力は基幹からするのが正しいよね？ でも棚卸が店舗や倉庫であったら？」

**一律に基幹起点、とは限らない。情報の種類で起点が分かれるのが一般的。**

| 在庫情報の種類 | 一般的な起点・正 |
|----------------|------------------|
| ① 入荷予定数 | 基幹（発注に紐づく） |
| ② 実在庫数 | 倉庫＝WMS／店舗＝POS（現場が正） |
| ③ 引当済数 | 基幹／OMS（受注に紐づく） |
| ④ 販売可能数 | 基幹／OMSで計算（＝実在庫−引当済〔＋入荷予定?〕） |
| ⑤ 出荷実績 | WMS／POS → 基幹へ |
| ⑥ 棚卸差異・在庫調整 | 現場（WMS／POS）で入力 → 基幹へ連携 |

→ **棚卸は現場（倉庫・店舗）で行い、差異を基幹へ返す**のが自然。  
　「基幹が唯一の入力元」ではなく、**基幹は集約・引当の正、現場は実数の正**、という二層で捉える。

### 想定フロー（案：予定は基幹起点／実績は現場起点）

```
YH／ジョイフル担当者 ─ 発注入力（アナログ可）─▶ 基幹 ─ 発注 ─▶ メーカー／仕入先
                                               │ 発注・入荷予定を連携
                                               ▼
メーカー ─ 納品 ─▶ WMS／倉庫・店舗POS ─ 入荷検品・実在庫 ─▶（実績を基幹へ戻す）
```

### 確認質問

- **Q6** 倉庫の実在庫の「正」は基幹ですか、WMSですか？ 店舗の実在庫は基幹ですか、POSですか？
- **Q7** 仕入発注は誰が・どのシステムで行いますか？（YH本部／ジョイフル／各店舗／アナログ）入荷予定は基幹に登録されますか？
- **Q8** 入荷検品はWMS／POSで入力し、実績は基幹へ自動連携されますか？ 全拠点の販売可能在庫はどこで計算していますか？
- **Q9** 棚卸はWMS／POSで入力し、差異を基幹へ連携しますか？ 在庫調整の承認者と、最終的な在庫の「正」はどこですか？

## 3. 図3：受注・引当・出荷フロー

`yh_asis_fig3_order.png`

### 想定フロー

```
取引先（ディーラー／整備工場／YH FC／中古車販売店?）
  ─ 電話・FAX・メール ─▶ 受注・卸担当（YH／ジョイフル）
        ─ 手入力？ ─▶ 基幹（受注データ生成・引当・出荷指示）
              ├─ 引当連携 ─▶ WMS／倉庫（引当・ピッキング）
              ├─ 引当連携 ─▶ 店舗POS（※引当できる？ 別システム？）
              └─ 直送手配 ─▶ メーカー直送
        出荷・在庫減算 ─▶ 取引先へ（商品受領）／実績を基幹へ戻す
```

### 注意（設計に効く論点）

- 引当を**基幹／WMS／店舗POSのどこで実行するか**で設計が変わる。
- **店舗POSがBtoBの引当・出荷指示を処理できるとは限らない**。店舗出荷は別の店舗在庫／作業システムの可能性。

### 確認質問

- **Q10** 電話・FAX・メール注文は、担当者が基幹へ手入力していますか？（おおよその比率・他手段も）
- **Q11** 引当は基幹／WMS／店舗POSのどこで実行しますか？ 店舗出荷時の指示はPOSですか、別システムですか？
- **Q12** 出荷完了・送り状番号・在庫減算はどこで登録し、基幹へどう戻しますか？ 自社倉庫／メーカー直送の振分けは誰が行いますか？

## 4. 先方への一括確認文（メール／打合せ用）

> Phase1の現状業務について、以下の理解で合っているかご確認させてください。
>
> **マスタ**：商品・顧客マスタは基幹が正で、YH様・ジョイフル様が登録。**顧客マスタは基幹に留まり、店舗POSへは連携しない**想定。商品マスタのみ WMS・店舗POS へ連携。適合情報は適合システムが正で、基幹とJAN等で紐付けている。
>
> **仕入・在庫**：仕入発注と入荷予定は基幹を起点とし、実際の入荷・出荷・棚卸は倉庫（WMS）・店舗（POS）で入力して基幹へ返している。基幹が各拠点の在庫を集約し、販売可能数を計算している。
>
> **受注・出荷**：取引先からの電話・FAX・メール注文を担当者が基幹へ手入力し、基幹で引当・出荷指示。自社倉庫出荷とメーカー直送を使い分け、出荷実績・在庫を基幹へ戻している。
>
> 特に、**①卸事業の管理主体（YH様／ジョイフル様）②在庫の“正”がどのシステムか ③店舗POSがBtoB出荷にどう関わるか**、の3点を重点的に伺えればと思います。
